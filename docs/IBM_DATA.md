# IBM independent synthetic benchmark

Publisher: IBM / Erik Altman. Dataset: HI-Small_Trans.csv, retrieved from the publisher-linked Kaggle dataset:
https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml
Publisher repository: https://github.com/IBM/AML-Data

IBM explicitly identifies the data as generated by a virtual-world multi-agent simulator, not anonymized customers. Labels describe simulated laundering. Do not relabel this as court-adjudicated fraud or independent real banking evidence.

Run `python ibm_benchmark.py --download` to retrieve the approximately 476 MB source, or use `--csv PATH`. The raw dataset is excluded from git and the deliverable. The script records its SHA-256 hash and row counts. Publisher states the data license is CDLA-Sharing-1.0 (distinct from the repository's code license). Review the publisher's current terms before redistributing raw or derived data; this project distributes evaluation summaries, not the source records.

The benchmark filters Payment Currency and Receiving Currency to Rupee and identical paid/received amounts, excluding FX. Bank + account identifies nodes. Features rebuild for three-day windows: Sep 1–3 training, Sep 4–6 validation, Sep 7–9 test (2022). Later dates are excluded from the temporal test. Labels are window-specific sender/receiver involvement, with no culpability inference.

Cross-generator transfer fits original FairFreeze data and uses a threshold selected from original OOF scores, then evaluates the IBM test window. Native temporal evaluation fits IBM training window only, selects its threshold on validation, and evaluates later test data. Models and thresholds never fit IBM test labels. Accounts can recur across periods; IDs remain excluded from inputs. Snapshot HITS uses only transfers in each period. Scores are retrospective at window end, not prospective at transaction time.

Few positives, one time split, context lost through currency filtering and synthetic label definitions limit conclusions. This benchmark provides no complaint references or complete opening-balance ledger for validating freeze amounts.
